# Legacy scripts

These scripts are environment-specific and are kept for reference only.

- `rssh_host.sh` opens a reverse-SSH tunnel through a local forwarded port.
- `rssh_remote.sh` is a template for starting a reverse SSH session. Replace
  the `<...>` placeholders before use.
- `git.sh` rewrites the `origin` remote URL. It is not needed for normal
  development.

They are not part of the supported deployment path.
